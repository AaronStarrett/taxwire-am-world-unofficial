# Implementation decisions

1. One browser-first TypeScript engine serves React 3D and the accessible workbench. React 19.3 / Fiber 9.8 / Drei 10.7 peer compatibility checked against current package metadata and Fiber's official React-major guidance. Three 0.186, Vite 8.3 and Vitest 5 run on an existing Node 24.19 runtime. TypeScript 5.9 is retained within typescript-eslint 8.71's supported range (<6.1). ESLint 10 and its matching config are used. Direct dependencies are exact-pinned; lockfile pins transitive resolution.
2. Navigation is a lightweight deterministic geometry grid/A* with wall/furniture collision and explicit door openings. No physics engine, model download, remote texture or proprietary font is needed. Procedural meshes are instanced by material. One Canvas owns rendering and is disposed on fallback.
3. Business time is action-based, starting on fictional day 1 at 09:00; animation does not own business time. Queues, capacity, deadlines and appointments use this clock and a saved seed. Time zones use explicit offsets rather than the execution host.
4. Structured choices, documentary dependencies and integer calculations drive grading. Drafts have model comparison/self-review, never an undisclosed text heuristic. Distinct case fingerprints, attempt modes and immutable histories prevent inflated import/mastery claims.
5. Public tax sources are research leads with professional review pending. All case deadlines, rates and internal approval procedures are fictional. No real tax liability is certified. Full public role inspected; public code contains an original scope paraphrase only.
6. Public/private separation is an explicit build boundary: only imported public content modules ship. Future private content is outside the repository; there is no environment flag that casually injects a private folder into the public build.
7. IndexedDB is browser-local. Portable history and engine-specific scene checkpoints are separate, versioned formats. Other-edition fixtures test the schema, not an actual integration with the independent Academy.
8. GitHub Pages publication was explicitly authorized by the deployment addendum. `main` releases only after lint/types/unit/content/campaign/build/public audit/browser checks. Development branches cannot deploy. No paid host, custom domain, or billing setting is used.
9. Storage verified as D: Extreme SSD / SanDisk Extreme 55AE / exFAT. New path and ancestor containment checked; write/readback passed. Git trust overrides are command-local. All controllable local artifacts reside in this project; host applications retain control of their own caches.
10. Initial content version `twaw-2026.10.03-v1`; initial authoring history consists of core/advanced/capstone and source-scope validation. Future content corrections require a new fingerprint/version and retained prior review. Candidate edits validate/export locally; they do not overwrite public teaching at runtime.

11. The continuation explicitly supersedes the original visible low-poly direction. The target is a contemporary refined semi-realistic workplace: smooth original anatomy and articulated adult proportions, furnished interiors, restrained physically based materials, a closer camera and selective roof/wall visibility. Historical choices above describe the earlier release; they do not require a block-shaped presentation. Supplied concept images are private visual references, without a redistribution license; they are not shipped as game backgrounds or assets. All new scene meshes and procedural surface textures are original authoring using the existing browser toolchain, with no asset purchase, generation credits, model service or global installation.
12. First-day guidance is a versioned, action-driven learning sequence separated from campaign mastery. It reuses the visible Cedarline discovery facts and real scheduling, notes, artifacts and tasks. Authored later responses teach bounded verification and residual ownership. Assisted mode and recorded help prevent coaching from silently being scored as unaided independent mastery. Existing learners may opt in; skipping or replaying never resets campaign history.
